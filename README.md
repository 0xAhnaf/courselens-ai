# CourseLens AI — AI Assessment Quality Auditor

An AI-powered academic decision-support tool for university faculty to evaluate syllabus/CLO coverage, question difficulty, and paper duplication.

## Project Structure
- `frontend/`: React + Vite UI
- `backend/`: Node.js + Express + SQLite API & AI Agent
- `docs/`: API Contract and Documentation

## Setup Instructions
1. Copy `.env.example` to `.env` inside `backend/`.
2. Install dependencies and run development servers.
